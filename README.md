# Placement Portal Application

A Flask-based placement portal for institutes to manage campus recruitment.

## Features
- Three roles: Admin, Company, Student
- Admin can approve/reject companies and drives, manage users
- Companies can create drives, view applications, shortlist students
- Students can apply to approved drives, upload resumes, track status

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Initialize database: `python init_db.py`
3. Run: `python app.py`
4. Default admin: admin@placement.com / admin123
